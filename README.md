# NGO platform

One platform for many NGOs. Vashundhara Foundation is the first. Each NGO gets its own website, donations with receipts, CRM, volunteers, beneficiaries, field work, learning, library, events, social planner, CSR grants and monitoring.

Start with [apps/docs/content/1-getting-started.md](apps/docs/content/1-getting-started.md), then [operations](apps/docs/content/3-operations.md) and the [security model](apps/docs/content/5-security.md).
